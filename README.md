# Twogether Food Studio
## Sobre el proyecto
Twogether Food Studio es una aplicación web para un establecimiento de restauración, inspirada en la estética de [Lisa Says Gah](https://lisasaysgah.com/). Se trata de un restaurante de concepto All Day Dining, que ofrece una propuesta gastronómica basada en platos contemporáneos y una experiencia pensada para compartir.

La aplicación cuenta con un sistema de autenticación y diferentes funcionalidades según el tipo de usuario:

 ### Cliente:
 - Puede seleccioanar productos
 - Realizar pedidos
 - Modificar ingredientes, ya sea añadiendo o quitando
 - Acceder a un panel personal desde el que puede:
     * Modificar datos personales
     * Ver historial de pedidos
  
  ### Administrador:
  - Listar, modificar y ordenar productos y pedidos
  - Gestionar los productos de los pedidos, permitiendo añadirlos o eliminarlos y modificar el precio final.
  - Consultar el listado de usuarios y acceder a su historial de pedidos
